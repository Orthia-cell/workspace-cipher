```markdown
### Search Preferences

- Primary: kimi_search (general web research)

- Patents: USPTO, EPO, WIPO (via web_search + fetch)
- Commercial: Company press releases, investor presentations
- Foundry: Process roadmaps, technology symposium proceedings

### Citation Format

- IEEE style for technical reports
- Full DOI or URL required
- Flag preprints clearly
- Note peer-review status

### Quality Heuristics

- Conference proceedings > press releases
- Foundry papers > startup whitepapers
- Measurement data > simulation-only claims
- Independent verification > self-reported
```
