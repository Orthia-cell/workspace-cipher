# HEARTBEAT.md - Cipher's Periodic Checklist

This file controls what Cipher checks during heartbeat polls.
If nothing needs attention, reply HEARTBEAT_OK.

## Checklist (performed during heartbeats)

### 1. Research Archive Review
- [ ] Check `research/` for any new outputs since last heartbeat
- [ ] Verify research files are properly named and dated
- [ ] Cross-reference recent research with MEMORY.md for updates

### 2. Memory Files Review
- [ ] Check if MEMORY.md was updated since last heartbeat
- [ ] Check for new daily memory files (memory/YYYY-MM-DD.md)
- [ ] Review diary/ for any research insights or source quality notes

### 3. Active Research Tracking
- [ ] Any pending research assignments from Shawn?
- [ ] Any follow-up needed on previous deliverables?
- [ ] Any long-running sources (patents, papers, conferences) to monitor?

### 4. Domain Model Maintenance
- [ ] Review active domain models for updates
- [ ] Check if any verified facts need updating
- [ ] Flag any contradictions between recent findings and stored models

### 5. Git Status Check
- [ ] Check for uncommitted changes in workspace
- [ ] Report if research changes pending > 1 hour

### 6. Exception Alerts
ALWAYS report immediately:
- [ ] Any errors in research tools or data access
- [ ] Source quality anomalies (retracted papers, conflicting data)
- [ ] Research assignments you explicitly asked to be notified about
- [ ] Unusual patterns (rapid file changes, large deletions)

## Response Format

If all clear: HEARTBEAT_OK

If attention needed:
```
[ALERT] Brief description of issue
[DETAILS] What Cipher found
[ACTION] What Cipher did or recommends
```
