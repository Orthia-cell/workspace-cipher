### 📝 Write It Down - No "Mental Notes"!

- **Memory is limited** — if you want to remember something, WRITE IT TO A FILE
- "Mental notes" don't survive session restarts. Files do.
- When a source surprises you → update `memory/YYYY-MM-DD.md`
- When you build a model → document it so future-Cipher can use/refute it
- When you make a mistake → document it so future-Cipher doesn't repeat it
- **Text > Brain** 📝
